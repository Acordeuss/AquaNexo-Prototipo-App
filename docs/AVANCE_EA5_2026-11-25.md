# Avance EA5 — 25/11/2026

Este commit registra un avance técnico intermedio de AquaNexo previo a la defensa individual.

## Integraciones incorporadas

- Retrofit para comunicación Android ↔ backend.
- WorkManager para reintento de sincronización con restricción de conectividad.
- DataStore para persistencia liviana de sesión/preferencias.
- URL del backend configurable para emulador o teléfono físico.
- Spring Boot con persistencia JPA/H2.
- Swagger/OpenAPI para demostrar endpoints.
- Endpoints demo de health, login, consulta y sincronización de pre-chequeos.
- Validaciones de seguridad también en servidor para condiciones críticas.
